设计规格 SPEC

页面结构去掉顶部标题文案;一天占一页 = 日头(今天/周几 + 日期 + 件数) + 当天卡片列表;默认落在今天,下拉刷新保留。
日期条(跳转组件)顶部横向滚动胶囊,覆盖未来 30 天;周内显「今天/明天/周几」,跨周显「10月13日」;选中黑底白字(深色反转)并自动居中。
有安排提示当天有安排的胶囊底部带 3px 小圆点;空日无圆点 —— 不翻页也能扫出哪天有事。
切换方式点胶囊跳转 + 当天页左右滑动换一天(PageView 语义);30 天边界回弹提示「没有更晚的安排」。
行程卡片白底、圆角 16、发丝边、轻投影;时间列 15px/700 + 竖分隔线 + 标题 15px/600 + 地点 12px;卡距 10。
状态语义「下一件」= 今天最近一条未完成:黑描边 + 悬浮倒计时徽标,只出现在今天页;已完成灰化 + 对勾。
空态空日 = 日头「N 没有安排」+ 虚线空卡 + 对话引导链接;页面不整页留白。
配色 / 数据完全复用 MobilePalette 浅/深两套;数据沿用现有解析(完成看 lastRunAt、未完成看 nextRunAt),30 天前瞻不变。
实现落点:重写 lib/mobile_ui/mobile_schedule_page.dart 展示层 —— 顶部横向日期胶囊条(ListView 联动) + PageView.builder 按天分页,删除 _header / _switchButton 与双视图状态;_parse 增加按日索引,其余不动。
